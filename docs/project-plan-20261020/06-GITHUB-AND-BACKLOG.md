# GitHub整合與工作清單

## 一 儲存庫與目錄

指定repo：https://github.com/Yun05617/future 。根README連到本計畫；既有應用位於voice-identity-emotion-chatbot/。文件放根docs/project-plan-20261020/，不要再上傳一個包含.venv及私人工作區的完整壓縮專案。

建議保留根AGENTS.md說明持續同步規則。後續功能更新以PR同步main，兩位開發者各自clone或worktree。Mac new-chat為既有工作目錄，不擅自更改其未提交狀態；逐功能搬移後再記來源commit。

本次整合新增計畫、runbook、契約、測試、提示詞、匿名CSV及可下載Word。文件包含未來需求，不代表本次已實作PIN或自然人像。公開PDF簽名、報名個資及私人照片不屬計畫附件。

## 三 每個PR的完成定義

只實作該任務，不混入重做介面、換模型及版本大升級。新增功能含具體失敗測試、權限檢查與文件。用合成資料重現；需GPU的結果另附硬體紀錄。檔案清單經過檢查，沒有私人素材或權重。相關測試通過後才提交，不用不相關的測試全部通過來取代實機影音驗證。

PR內說明「前後行為、執行方式、測試證據、限制」，附commit及模型版本。對主程式不能使用的環境，明確標未測。由另一位開發者審閱，main保持可啟動。沒有團隊確認不改public/private、不移除歷史、不強推、不自動替所有素材加授權。

## 五 長期同步規則

使用者已要求本專題後續更新同步到此repo。流程是讀取現況→小分支→實作/文件→驗證→推送→PR→回報連結。若無網路或GitHub權限失效，完成本機可交付部分並明確標「尚未同步」，不能把本機commit當成已上傳。不得把「同步」理解為自動公開原始錄音、替人發訊息或合併所有PR。
