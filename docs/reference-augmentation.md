# 參考簡報的聲音擴增工具

雙擊專案根目錄的「啟動聲音擴增工具.bat」。預設使用 http://127.0.0.1:7876/，被占用時依序改用後續連接埠，不會關閉聊天或訓練服務。使用既有 Python 環境，不下載新模型。

可批次上傳或錄音，勾選方法，各方法獨立從原始音訊產生一份副本，不會依序疊加。結果包含原音與副本試聽、處理明細及 ZIP 下載。

## 與參考資料的對應及限制

參考使用者提供的《華語語音情緒辨識(1).pptx》，陳臻儀，2019/07/21，第 23–25 頁。

- 第 23 頁「聲音旋轉」：圖中在約 40% 處切開，將後 60% 移到前面，前 40% 接到後面。本工具用時間循環位移實作，保留取樣值與總長度，不反轉播放。接點可能產生聲響，字句順序會改變，不能用於保留原逐字稿的 ASR 訓練。
- 第 24 頁「聲音調音」：文字寫「降低 25% 頻率」，波形卻呈現較短時長，沒有公開程式或精確公式，因此無法確定演算法。本工具另列「變速調頻」近似實驗：倍率 0.75 讓頻率成為原本 75%，時長變為約 1/0.75。這不是宣稱復現該圖。
- 第 25 頁「音高調整」：文字同樣寫降低頻率，圖形較像音量降低。本工具將「音量調整」（預設乘 0.75）與「固定時長變調」（預設 -4 半音）明確分開，不將兩者視為相同。
- 降低頻率 25% 的固定時長音高對應約 -4.98 半音，不等於 -4 半音。需要時可設 -5 半音作近似。

此為參考概念的小工具，不是論文精確重現。原研究為情緒辨識，不能把簡報的 88.9% 當成此工具或身分辨識的效果。時間旋轉也不能保證嵌入向量不變。

## 資料安全及評估

實驗批次位於 `outputs/reference-augmentation/<隨機批次編號>`，包含來源原檔備份、16 kHz 單聲道預覽、處理結果、manifest 與 ZIP。原始來源檔不會修改。ZIP 僅含副本和 manifest，不含來源備份。

manifest 保存來源 SHA-256、來源群組、方法、參數、削峰倍率，以及身分與情緒保留情形「尚未驗證」。不自動加入身分資料、情緒資料或重建模型。重複來源內容會去重，一次最多 100 檔且總長不超過 30 分鐘。不會讀取既有聲紋、對話或模型。下載服務只提供本批次的明確輸出，不開放整個專題資料夾。

先分割原始錄音，再只擴增訓練部分。同一來源及所有衍生版本必須在同一組，不能跨訓練與測試。比較身分辨識範本時使用固定、獨立的真實錄音，並同時檢查其他人被誤認的情況。請勿把實驗音檔、manifest 或來源備份公開上傳 GitHub。

實作 API：<https://librosa.org/doc/latest/_modules/librosa/effects.html>，使用 librosa 的 pitch_shift 及 resample，沒有聲音複製或聲紋轉換模型。
