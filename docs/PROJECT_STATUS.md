# 目前狀態與資料管理

## 本次整理範圍

收錄最新的語音、身分分類器、情緒、轉寫、聊天、擴增與評估程式、測試及必要角色圖，本小組交接版另附原有訓練錄音及分類器。`requirements.txt` 沿用原環境版本，未在全新電腦重新下載安裝驗證。

已整合更新時重訓身分分類器、模型 revision 快取、品質提醒、原子發布、三介面啟動及前台三欄信心度顯示。底層 ECAPA-TDNN 與 XLS-R 仍固定。公開版另將預設資料路徑設在忽略的 `workspace/`，移除個人測試日期假設。整理上傳版不修改原展示環境。

## 待整合或實機確認

- 語音回覆：有 Windows 合成介接與測試，仍需確認系統語音、瀏覽器播放及權限。
- 嘴型同步：目前角色圖為靜態圖片加漸入效果，沒有音素同步動畫。
- 臉部輔助識別：依本次整理範圍先不納入。
- 身分門檻：前台及後台使用未四捨五入的分類器支持度 ≥ 80% 才接受身分。餘弦相似度不參與介面決策；底層舊版 hybrid 模式及部分實驗指標只供對照。支持度不是實際準確率，陌生人也可能取得高支持度。
- 信心度顯示：代表身分分類器支持度，不是聲音情緒的分數；歷史分析檔缺失時顯示「—」。

## 交接資料範圍

本小組交接版依要求保留訓練錄音、身分特徵、個人分類器與訓練報告。聊天原音、逐字稿、聊天紀錄、對話分析、憑證、API 金鑰及 `.env` 不附帶。實際交接內容與啟動方式見根目錄 README_交接必讀.md。

此版保留程式預設的四位成員姓名，因為它們是既有登錄設定。若需要匿名公開，請先由團隊確認，再同步修改 `speaker_identity.py` 與 `workspace.py`；不要只改介面顯示名稱。

測試內的音訊由程式生成，不是成員錄音。角色圖片是既有介面資產，不是成員的人臉登錄資料；圖片公開使用及授權需由團隊確認。

`reports/provenance.md` 為歷史來源紀錄，不表示本次重新審核第三方條款或競賽資格。本機預訓練權重不隨 repository 發布。公開來源與授權不等於競賽資格保證。
