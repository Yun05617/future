# 音高擴增實驗

在訓練後台「加入訓練錄音」選取錄音或音訊檔，再展開「音高擴增（實驗）」。預設升高四個半音，可選 -12 至 +12 的非零整數半音，按「產生變調副本」下載 ZIP。

這裡的 +4 指四個半音，不是四個全音，也不是產生四種不同變化。每個原音產生一份變調 WAV，音高倍率為 `2 ** (4 / 12)`，約 1.26 倍；採 librosa 的 pitch_shift，不以直接加速播放代替升調，取樣率與時長維持一致。

原始音訊不改動。產物位於研究工作區的 `09_資料擴增/音高實驗/<批次編號>/`，ZIP 含 WAV 與 `manifest.json`，記錄來源檔名、來源雜湊、group_id、半音數及必要的防破音增益調整。同一批內容相同的來源只輸出一次。

批次資料夾的 `originals/` 另外保留來源音檔的原始位元組備份，避免麥克風暫存檔清理後失去來源。下載 ZIP 不含此原音備份；後台只將 ZIP 複製到系統暫存目錄供 Gradio 下載，不開放整個私人工作區的存取。

## 使用限制

- 變調會改變聲音的部分特徵，不能保證聲紋身分或情緒標籤不變，更不能保證提高相似度。
- 此工具只匯出實驗資料，不自動加入聲紋登錄、情緒資料夾或重訓模型；原始模型及範本不變。
- 情緒欄位僅記錄使用者選擇的來源標籤，並未驗證變調後仍屬於同一情緒。
- 目前情緒分類訓練未整合同來源擴增分組。不要把所有副本直接混入後再以原有隨機／檔名切分宣稱測試提升。
- 正確整合方式是先切分原始錄音，僅對訓練組擴增；同一 group_id 不可跨訓練與測試。最終評估使用未經擴增的新真人錄音。
- 增加檔案數不代表增加同等數量的獨立真人樣本。若要用於身分辨識，需另行比較本人與其他人的分數及誤認情形。
- 這些產物含私人語音與來源資料，不應公開上傳 GitHub。

## 命令列

在專案根目錄、已安裝原有 requirements 的 Python 3.12 環境中執行：

```powershell
$env:PYTHONPATH = Join-Path $PWD 'src'
.\.venv\Scripts\python.exe scripts\augment_pitch.py recording.wav --output-root outputs\pitch-experiments --semitones 4 --emotion calm
```

多個原音可依序列在參數中。輸出路徑不可包含本批來源，以免重複擴增自己的產物。新功能不需下載額外模型或引入新的變聲服務。

使用既有 librosa 套件。方法說明：https://librosa.org/doc/latest/_modules/librosa/effects.html
