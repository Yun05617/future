# 語音情緒辨識使用手冊

目前展示使用三類個人情緒模型：`positive`（正面）、`negative`（負面）、`calm`（平靜）。四類 baseline 則是另外保留的訓練流程，不要混用標籤或模型。

## 啟動訓練頁

完成根目錄 README 的安裝後，執行：

```powershell
.\start_windows.ps1 -Mode training
```

對應的 Python 入口是 `scripts/run_personal_demo.py`。直接執行時需先設定 `PYTHONPATH`：

```powershell
$env:PYTHONPATH = Join-Path $PWD 'src'
.\.venv\Scripts\python.exe scripts\run_personal_demo.py
```

開啟 http://127.0.0.1:7860/。此頁只在本機執行，錄音前需允許瀏覽器使用麥克風。

## 個人三類情緒流程

1. 分別選擇正面、負面、平靜，錄製或上傳音訊後加入訓練資料。
2. 每類至少兩段，最低共六段；這只是確認流程可用的最低資料量。
3. 執行個人 Demo 訓練，查看 Accuracy 與 Macro F1。
4. 使用未加入訓練的另一段錄音進行分析，檢查結果；需要時人工修正標籤，再明確執行訓練更新。

這份評估屬於**同一位說話者測試**，不代表對陌生使用者、其他麥克風或噪音環境的準確率。請另外保留真正的測試資料，不要把展示測試音檔再混進訓練資料後宣稱辨識率。

錄音、特徵與分類器存入被 Git 忽略的 `data/raw/`、`data/processed/`、`models/`；身分登錄與整合分析資料另存於 `workspace/`。

## 四類 baseline

四類 baseline 使用 `neutral`、`happy`、`angry`、`sad`，由 XLS-R 固定特徵與 SVC 分類器組成。範例 manifest 只有格式、沒有音檔；實際訓練需另備經同意蒐集的資料，並將同一位說話者限制在同一個 split。指令見 [Windows 操作說明](SETUP_WINDOWS.md)。

## 常見檢查

- 轉檔失敗：確認 `ffmpeg -version`，FFmpeg 不是僅下載原始碼壓縮檔。
- 模型尚未訓練：先補足三類資料並執行訓練，不要把缺少模型誤認成麥克風故障。
- 首次下載語音權重較慢：需先連網下載，完成後使用 `.cache/` 的本機快取。
- 聲音情緒只供對話參考，不是心理或醫療診斷。
