## 不能公開的資料

請勿提交原始錄音、身分特徵、個人訓練模型、逐字稿、聊天紀錄、含真實路徑的報表、憑證、API 金鑰及 `.env`。上傳前必須檢查 Git 實際待提交的內容，不能只依賴副檔名過濾。

此版保留程式預設的四位成員姓名，因為它們是既有登錄設定。若需要匿名公開，請先由團隊確認，再同步修改 `speaker_identity.py` 與 `workspace.py`；不要只改介面顯示名稱。

測試內的音訊由程式生成，不是成員錄音。角色圖片是既有介面資產，不是成員的人臉登錄資料；圖片公開使用及授權需由團隊確認。

`reports/provenance.md` 為保留的歷史來源紀錄，不表示本次已重新審核所有第三方條款或競賽資格。本機預訓練權重不隨 repository 發布。
