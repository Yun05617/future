## 下載

在本機專案目錄執行 `python3 mac/download_weights.py`。此工具只下載語音驅動所需的九個檔案，使用 `.part` 續傳。不要同時開啟兩份下載工作。
下載狀態可查看 `logs/download.log`。出現 `All required files downloaded` 才代表這組檔案已下載齊全。
請勿在下載或推論時拔除硬碟；需先停止工作，再由 Finder 退出硬碟。

## 安裝與測試（仍待完成驗證）

```bash
uv venv --python 3.10 .venv
uv pip install --python .venv/bin/python -r mac/requirements.txt
PYTORCH_ENABLE_MPS_FALLBACK=1 .venv/bin/python mac/check_device.py
./mac/run.sh
```

`requirements-tested-macos.txt` 保存目前測試環境的精確版本，僅供此 Mac 環境重建參考，不代表 Windows 相容性已驗證。

`run.sh` 使用 256×256、24 影格、12 FPS、10 步，僅為約兩秒的相容性測試，並非最終品質設定。使用官方範例照片與音訊。完成的影片位於本機 `output`。
要測試自己的照片與音訊，修改 `configs/prompts/animation_mac.yaml` 的 `test_cases`；未完成這輪測試前，不建議直接接入聊天機器人。

語音特徵與 MTCNN 人臉偵測以 CPU 執行，影像生成以 MPS 執行，並允許 PyTorch 支援的 CPU fallback。這不保證所有運算都能 fallback，也不保證 16 GB 記憶體足夠。官方 WebUI 和 pose/accelerated 入口尚未移植，請勿把它們當作 Mac 可用版本。

## 已定位的 Mac 相容性問題

- PyTorch 2.2.2 的 MPS 不支援此處使用的 Conv3d；目前使用 2.8.0，已通過獨立 FP16 Conv3d 測試。
- 本機 SciPy 1.15.3 發生動態載入錯誤，目前固定使用 1.14.1。
- MTCNN 的 adaptive pooling 在 MPS 發生非整除尺寸錯誤，因此僅將人臉偵測改為 CPU，官方範例偵測成功。
- 不安裝音訊驅動入口未使用的 MediaPipe；此環境不保證姿態驅動入口可用。
- 外接硬碟讀取大型權重耗時；首次載入和實際生成耗時需分開記錄。

目前完整測試指令：`./mac/run.sh -L 12 --steps 2`。這是約一秒、兩步的相容性檢查，不能用來判定自然度、完整回答延遲或產品品質。日誌：`logs/smoke-mps-cpu-face.log`。
