# 照片說話本機測試頁

使用者已選擇先建立照片＋音訊上傳測試平台，接受等待完整影片生成。沿用 Mac 上已完成短片推論的 EchoMimic，不在本版替換模型或承諾一秒生成。

介面：米白色、照片與音訊上傳、品質選擇、生成／取消、狀態及計時、影片預覽與下載。僅監聽 127.0.0.1，不開公共分享。

執行：每次工作獨立資料夾，輸入驗證後啟動現有推論入口；顯示模型載入及生成階段。單一工作防止多份模型耗盡記憶體。首版每次仍需載入模型，不承諾常駐加速。

限制：音訊 0.5–5 秒完整生成、不偷偷截斷；圖片使用 Pillow 驗證與縮放；FFmpeg 標準化音訊；影音合成單一 MP4，長度相差不超過一影格加編碼容差。這不代表每個音素的嘴型品質已驗證。

方案比較：沿用 EchoMimic 可立即比較真實輸出；更換即時模型涉及另一輪部署與驗證，延後。瀏覽器假嘴型不符合使用者想看模型效果的目的，不採用。
