# 照片說話測試平台

雙擊專案根目錄的「啟動照片測試平台.command」，或在 EchoMimic 目錄執行：

```bash
bash mac/start_test_ui.sh
```

網頁：http://127.0.0.1:7881 。終端機需保持開啟。若第一次打開時尚未連線，等終端機啟動後重新整理。

1. 連接 KATHY 外接硬碟。
2. 上傳一張單人正面照片，照片會顯示在預覽區。
3. 上傳 0.5～5 秒音訊，或錄製後按「使用這段錄音」。未來聊天模型產生的語音也可上傳測試。
4. 選擇品質：2 步為流程檢查，可能模糊或變形；建議先用 1～3 秒音訊、10 步查看效果。
5. 按「生成說話影片」，查看工作狀態。完成後播放或下載 MP4，也可下載工作日誌。
6. 需要停止時按「取消目前工作」。一次只執行一個工作，請勿多個分頁同時送出。

每次工作目前都重新載入模型；外接硬碟冷載入曾約 13 分鐘，一秒影片的兩步去噪曾約 25 秒。這不是即時對話模式，不承諾一秒內生成。

照片、標準化音訊、設定、日誌及結果存於 `output/web_tests/<工作編號>`，Gradio 上傳暫存位於 `output/ui_uploads`。取消後的部分資料仍保留。工作停止後可自行刪除不需要的工作資料夾。沒有公共分享連結，也不會將使用者素材同步到 GitHub。

平台確認輸出有音軌、畫面且長度與輸入相符；這不等於音素嘴型或人物自然度通過評測。長音訊、正式模型語音串接、常駐模型及即時串流屬於後續工作。
