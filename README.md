# 具身分辨識與情緒感知的聊天機器人

多人共用的本機語音陪伴專題，包含聲紋候選、三類聲音情緒、繁體中文轉寫及本機對話。應用程式放在 [voice-identity-emotion-chatbot](voice-identity-emotion-chatbot/README.md)。

## 計畫與執行

[2026/10/20 完整計畫與操作文件](docs/project-plan-20261020/README.md) 包含四週分工、Windows／Mac執行、PIN與記憶流程、照片說話契約、測試表及可直接使用的提示詞。

本次新增的是開發計畫。PIN保護、經確認長期記憶及自然說話影片尚需依計畫實作驗證；不能以本文件當完成證據。人像完整影片與既有靜態人物顯示不是同一項功能。臉部融合及影片音色列後續階段。

## 啟動現有版本

目前GitHub整理版本以Windows入口為主；[操作手冊](docs/project-plan-20261020/02-RUNBOOK.md)明確區分遠端版本與Mac本機開發版。兩頁網址為訓練後台 http://127.0.0.1:7860/ 及展示 http://127.0.0.1:7862/ ，需要在自己的電腦啟動服務。
